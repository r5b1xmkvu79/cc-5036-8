Packaging Fold Preview

Fold convention: 0° = flat net, positive angle = valley (child toward +z), negative = mountain (child toward −z). Rotation axis points opposite the parent hinge edge (right-hand rule). Hinge tree plus optional packaging seams; mismatched hinge or seam lengths are rejected, never repaired by scaling.

Start the interface with npm start and open http://localhost:5173/. Hinge angles, seams and packaging mode all drive the same evaluated geometry shown in 2D and 3D.

Scope

This tool evaluates exact rigid-fold geometry from your parameters. A visually closed shape does not imply manufacturability, sealability, or structural strength — material thickness, crease tolerances, collision and load behavior are not modeled. Interference shown here is strict triangle-level panel crossing; it is not a clearance or thickness simulation. See deliverables/packaging-solve.md for the assumption list that still needs physical validation.
